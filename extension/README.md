# iKuuu Cookie 自动同步扩展

适用于 Chrome 116+ 和支持 Manifest V3 的新版 Edge。与本项目 Cloudflare Worker 配合使用，无需付费验证码服务或 AI 服务。网站要求验证码、邮箱或二次验证时，在官方网站正常完成登录即可，扩展自动传递 Cookie。

## 首次安装与配对

1. **先部署新版 Worker。** 本扩展需要 `/api/sync/cookie` 接口和管理页面的“浏览器扩展自动同步”功能。仅安装扩展无法更新旧 Worker。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启“开发者模式”。点击“加载已解压的扩展程序”，选中含有 `manifest.json` 的 `extension` 文件夹。如果使用 ZIP，先解压，选择解压后包含该文件的目录。
3. 打开自己的 Worker 管理页面并用管理密码登录。在“浏览器扩展自动同步”中输入设备名称，如“家用 Chrome”，点击“生成扩展配对令牌”。令牌只显示本次，复制备用；遗失时撤销该设备并重新生成。
4. 点击浏览器工具栏中的本扩展。填写 Worker 的 **HTTPS 根地址**（例如 `https://your-worker.your-subdomain.workers.dev`），不要附加 `/api`。填写配对令牌，填写实际使用的网站地址（例如 `https://ikuuu.top`，多个以换行或逗号分隔）。仅填写自己确认的官方网站。
5. 点击“保存并启用自动同步”，允许访问所填写的网站和 Worker。扩展只申请这些具体地址的权限。
6. 在同一浏览器的普通窗口中打开所配置网站，正常登录并进入 `/user` 账户页面。扩展检测到剩余流量后同步；检查扩展“最近同步”和管理页面“最近浏览器同步”。安装前已经打开的标签页可刷新，或点击“同步当前网站”。

若配置时浏览器已有有效登录，扩展会立即同步。此后每个已登录账户页面会发出一次同步信号；同一文档的重复信号会合并。**即使 Cookie 与上次相同，登录进入账户页面仍会重新验证并同步一次。** UID、密钥、到期标记或会话 Cookie 变化也会触发同步，短时间内的删除/写入通知会合并。

## 日常使用

- 无需保持管理页面登录：扩展使用独立配对令牌，不受管理会话 7 天到期影响。网站会话本身到期时仍要登录网站，扩展无需再次配对。
- 浏览器关闭后，Cloudflare 继续使用最后同步的 Cookie 签到。浏览器关闭时无法获取新的浏览器 Cookie；临时网络失败的同步任务会在浏览器恢复运行后继续。
- 临时网络、云端验证故障或限流按 **1、5、30 分钟**重试，最多四次；状态和剩余任务保存在扩展存储中。耗尽后点击“同步当前网站”，或重新完成网站登录。
- Cookie 同步不会重复当天成功的签到，也不会重置当天耗尽的签到次数。管理员暂停的签到仍保持暂停。
- 配对即切换到浏览器模式，停止服务器密码自动登录。`IKUUU_EMAIL`、`IKUUU_PASSWORD` 不再需要，已有值不会被覆盖，可在 Cloudflare 自行移除。撤销配对不自动恢复密码自动登录。
- 网站更换域名时，在扩展中添加实际新网站地址、保存并授权；服务器会验证新域名的登录页和账户页后才采用它。

## 撤销与更换设备

管理页面设备列表中的“撤销配对”立即使对应令牌失效。扩展收到 401 后停止自动尝试，在管理页面生成新令牌并重新保存扩展设置即可恢复。

扩展“清除本机配对”删除本机令牌和等待任务，不会替你撤销云端令牌；停用设备时请同时在管理页面撤销。修改或通过恢复码重置管理密码会撤销全部扩展令牌，需要重新配对。普通退出管理页面不会撤销扩展。

## 常见问题

| 提示或现象 | 处理 |
| --- | --- |
| 404 / 无法识别服务响应 | 确认 Worker 已部署新版本，扩展填写 HTTPS 根地址 |
| 没有有效登录 Cookie | 在同一浏览器普通窗口登录所配置网站，再进入账户页面；不支持无痕窗口 |
| 配对已失效 | 在管理页面生成新令牌，粘贴并保存 |
| 浏览器账号不匹配或 Cookie 较旧 | 登录当前签到账户，必要时重新登录刷新 Cookie；服务器保留原凭证 |
| 云端无法验证 / 正在重试 | 云端访问网站可能失败或受挑战，等待重试并查看状态；有效浏览器登录不保证云端能访问 |
| 网站或服务权限已移除 | 重新保存扩展设置，允许访问配置地址 |
| 登录后没同步 | 确认网站地址在配置中、已经进入 `/user` 且显示剩余流量；刷新账户页或点击“同步当前网站” |

本服务按单一签到账户工作。若有意更换账号，先通过管理页面的手动 Cookie 更新入口提交新账号 Cookie，再让扩展同步该账号；扩展不会悄悄替换不同 UID。

## 凭证处理与验证

扩展通过浏览器 Cookie API 读取含 HttpOnly 的 Cookie，不读取网站密码、不保存原始 Cookie。令牌保存在本机扩展存储中，网站内容脚本不能访问；同步仅发往设置的 HTTPS Worker，不携带管理会话，禁止重定向。云端存储令牌摘要，Cookie 延续现有加密存储。配对令牌仅能同步 Cookie，不能读取历史或操作调度。

仓库 `npm run build` 覆盖 Cookie 读取、登录触发、重复通知合并、持久重试、令牌撤销及真实 Workers 运行时的调度恢复等行为，并执行 Worker dry-run。测试使用模拟网站响应，不进行真实账号登录、签到或发邮件；首次实际安装后请核对两端同步时间。
